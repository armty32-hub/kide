# 🎪 สวนสนุกเสริมพัฒนาการ 30 เกมสำหรับเด็ก (Kids Developmental Arcade)

ศูนย์รวมเกมเสริมพัฒนาการสำหรับเด็กปฐมวัย (อายุไม่เกิน 6 ขวบ) จำนวน 30 เกม ครอบคลุมทั้งคณิตศาสตร์ ภาษาไทย ความจำ กล้ามเนื้อมือ และดนตรี พร้อมระบบ **Dual-Screen** แสดงผลบนจอคอมพิวเตอร์/โน้ตบุ๊ก และใช้โทรศัพท์มือถือเป็นจอยกด (Gamepad Remote) สั่งการแบบเรียลไทม์ผ่าน WebSockets

---

## 🌟 จุดเด่นของโปรเจกต์

1. **30 เกมเสริมพัฒนาการครบวงจร**:
   - 📖 **ภาษาไทย & นิทาน (6 เกม)**: นิทานภาพมีเสียงเล่า (กระต่ายกับเต่า, ลูกหมูสามตัว), สะกดคำสระหรรษา, ตลาดคำศัพท์, สระไทย, เพลงเด็กอนุบาล, เรียงประโยค
   - ➕ **บวกเลข & คณิต (8 เกม)**: บวกเลขผลไม้, รถไฟบวกเลข, ทอยเต๋าวิเศษ, ร้านค้าขนมหวานคิดเงิน, นับผลไม้ 1-10, เทียบขนาด, เติมเลขลูกโป่ง, ต่อบล็อกรูปทรง
   - 🧠 **ความจำ & สังเกต (4 เกม)**: เปิดป้ายจับคู่สัตว์, จับคู่เงาปริศนา, หาภาพที่ไม่เข้าพวก, ใครแอบอยู่หลังพุ่มไม้
   - 🎨 **สีสัน & จำแนก (4 เกม)**: เก็บของใส่ตะกร้าตามสี, แยกบ้านสัตว์ บก-น้ำ-ฟ้า, ผสมสีเวทมนตร์, ให้อาหารสัตว์ตามที่ชอบ
   - ⚡ **กล้ามเนื้อมือ & สายตา (4 เกม)**: จิ้มลูกโป่งแตก, จับผีเสื้อในสวน, เคาะกลองตามจังหวะ, ลากเส้นต่อจุดดวงดาว
   - 🎵 **ดนตรี & ศิลปะ (4 เกม)**: เปียโนเสียงสัตว์ 8 โน้ต, ทายเสียงสัตว์, แฟลชการ์ด ก-ไก่ & ABC, จานสีระบายใจ
2. **ระบบสองหน้าจอ (Laptop Display + Mobile Gamepad)**:
   - จอโน้ตบุ๊กแสดงภาพการ์ตูนขนาดใหญ่และเสียงประกอบ
   - มือถือทำหน้าที่เป็นจอยกด มีระบบสั่น และเลือกเกมจากมือถือได้ทันที
3. **ระบบเสียงในตัว (Zero External Dependencies)**:
   - สังเคราะห์เสียงด้วย Web Audio API และอ่านออกเสียงภาษาไทยด้วย SpeechSynthesis API ไม่ต้องต่อเน็ตโหลดไฟล์ mp3

## 🚀 วิธีเปิดเล่นในเครื่อง (Local Setup)

1. ติดตั้ง Node.js (เวอร์ชัน 18 ขึ้นไป)
2. ติดตั้งแพ็กเกจ:
   ```bash
   npm install
   ```
3. เริ่มต้นเซิร์ฟเวอร์:
   ```bash
   npm start
   ```
4. เปิดเบราว์เซอร์:
   - **หน้าจอคอมพิวเตอร์**: `http://localhost:3001`
   - **โทรศัพท์มือถือ**: สแกน QR Code บนหน้าจอคอมพิวเตอร์ หรือเข้าผ่านลิงก์ `http://<IP-เครื่องคอม>:3001/controller.html`

## 🌐 การ Deploy ขึ้น Cloud (เช่น Render.com)

1. อัปโหลดโค้ดขึ้น GitHub
2. เข้า [Render.com](https://render.com) -> เลือก **New Web Service**
3. เชื่อมกับ Repository นี้
4. ตั้งค่า:
   - **Build Command**: `npm install`
   - **Start Command**: `node server.js`
5. กด **Deploy** จะได้ลิงก์ HTTPS ให้น้องๆ เล่นได้จากทุกที่ทันที
